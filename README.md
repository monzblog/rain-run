# rain-run — 雨の中、走る？歩く？

## Purpose
傘なしで雨の中を 30m 移動したとき、歩くのと走るのでどちらがどれだけ濡れるかを、
雨粒を 1 粒ずつ降らせる物理シミュレーションで「見える化」する。

## Target User
「雨の日は走った方が濡れない？」という素朴な疑問を持つ人。理科・物理の教材としても。

## Problem
よくある議論は数式だけで直感がつかみにくい。体のどこが濡れるかも分からない。

## MVP
- 雨量 (mm/h)・A/B 2 人の速さ・風（追い風／向かい風）を自由に変更
- 2 レーン並走で 3D 表示、濡れた量 (mL) をリアルタイム表示
- 体の部位ごとの濡れ量、濡れマップ（頂点単位で当たった位置を着色）
- 速さ→濡れる量の理論曲線とシミュレーション結果の比較

## 物理モデル
- 雨粒: Marshall-Palmer 分布（0.5–6 mm）、終端速度は Atlas (1973) 近似。
  指定した降水強度になるよう分布を正規化
- 人体: 14 個のカプセル。速さに応じて歩き⇔走りの歩容（ピッチ・歩幅・膝・腕振り・前傾）が変化
- 衝突: ランナーと一緒に動く箱の中で雨粒を 1/120 秒刻みで動かし、
  手足の動きを含めた相対運動で線分×カプセルの交差判定
- 理論値: 雨の相対速度方向から見た体の投影面積（歩容平均・ラスタライズ）× 雨水量密度 × 相対速さ × 時間
